House Guard for Homey Pro. Use the setup wizard to select people and lights for home, away and night. Add guest mode as a switch in Homey.
Basic setup needs no helper flows. Mobile notifications, night questions and Sonos use simple Flow connections with recipes in the app.
Starts in observation mode without controlling devices or sending messages. Simple connections have no automatic fallback push or delivery receipt.
Local development release. Physical effects and actual delivery still require testing. The settings interface is currently in Norwegian.

House Guard for Homey Pro. Use the setup wizard to select people and Homey Flows for home, away and night. Add guest mode as a switch in Homey.
Create a Flow such as “Turn off all lights” in Homey, then select it in the wizard. Mobile notifications, night questions and Sonos use simple Flow connections with recipes in the app.
Starts in observation mode without controlling devices or sending messages. Simple connections have no automatic fallback push or delivery receipt.
Local development release. Physical effects and actual delivery still require testing. The settings interface is currently in Norwegian.
